Detailed Description

Two-Level Segregated Fit allocator.

Adaptation of jserv/tlsf-bsd into a single-header library that also works on Windows + MSVC. The address range for the whole allocator is reserved from the OS up front by tlsf_init and pages are committed on demand.

In exactly one source file, define TLSF_IMPLEMENTATION before including tlsf.h.

Define TLSF_ENABLE_CHECK to make tlsf_check verify the allocator's internal structure, otherwise it is a no-op.

The original code is distributed under the BSD-3-Clause license, see jserv-tlsf-bsd-LICENSE.md in the repository root.
