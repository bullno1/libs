Detailed Description

Logging with the formatting of bfmt.h through blog.h.

BFMT_INFO("Copied ", num_files, " files to ", path);
// [INFO ][src/main.c:12]: Copied 3 files to /tmp
BFMT_INFO
#define BFMT_INFO(...)
Log at BLOG_LEVEL_INFO.
Definition bfmt_log.h:53

Everything bfmt_print accepts works here: bfmt for options, bfmt_with for a specific formatter and the types listed in BFMT_USER_TYPES.

Messages longer than BLOG_LINE_BUF_SIZE are truncated.

In exactly one source file, define BFMT_LOG_IMPLEMENTATION before including bfmt_log.h. BLIB_IMPLEMENTATION does that for this header, bfmt.h and blog.h at once.
