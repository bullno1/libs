Detailed Description

Commonly used macros.

  • Type and memory helpers: BCONTAINER_OF, BCOUNT_OF, BTYPEOF.
  • Preprocessor helpers: BCONCAT, BSTRINGIFY, BLIT_STRLEN.
  • X-macro generators: BENUM, BMASK_ENUM.
  • printf-style format checking: BFORMAT_ATTRIBUTE, BFORMAT_CHECK.

Everything is a macro so there is no implementation to define.

◆ BFORMAT_CHECK

#define BFORMAT_CHECK (   ...)

Check printf-style arguments on any compiler.

The arguments are only type-checked, never evaluated, so this costs nothing at runtime. Typically used in a wrapper macro around a function marked with BFORMAT_ATTRIBUTE. Requires <stdio.h>.
