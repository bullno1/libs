Detailed Description

Command line argument parser.

In exactly one source file, define BARG_IMPLEMENTATION before including barg.h.

Declare the options in an array of barg_opt_t, reference it from a barg_t and call barg_parse. Parsed values are written through the parsers assigned to each option (barg_int, barg_boolean, barg_str, barg_array or a custom barg_opt_parser_t).

Both --option value and --option=value are accepted, as well as -o value and -ovalue for short names. A lone -- marks the end of options.

Use barg_print_result to report an error or print the help text depending on the result of barg_parse.

Example:

barg_opt_t opts[] = {
{
.name = "optimize",
.short_name = 'O',
.value_name = "level",
.summary = "Optimization level",
.parser = barg_int(&level),
},
{
.name = "verbose",
.short_name = 'v',
.summary = "Print more details",
.boolean = true,
.parser = barg_boolean(&verbose),
},
{
.name = "output",
.short_name = 'o',
.value_name = "file",
.summary = "Where to write the output",
.parser = barg_str(&output),
},
{
.name = "define",
.short_name = 'D',
.value_name = "name",
.summary = "Define a macro",
.repeatable = true,
.parser = barg_array(&defines_opts),
},
{
.name = "color",
.value_name = "mode",
.summary = "When to use colors",
.description =
"One of: auto, always, never.\n"
"Defaults to auto.",
.parser = {
.userdata = &color,
.parse = parse_color,
},
},
// The standard --help option
barg_opt_help(),
};

BARG_API barg_result_t barg_parse ( barg_t *  barg,
int  argc,
const char *  argv[] 
)

Parse the command line arguments.

argv[0] is assumed to be the program name and is skipped. Parsing stops at the first positional argument or at a lone --.

Parameters
bargThe parser.
argcNumber of arguments, as passed to main.
argvThe arguments, as passed to main.
Returns
The result of the parse. On BARG_OK, arg_index is the index of the first positional argument.

Example:

barg_t barg = {
.opts = opts,
.num_opts = sizeof(opts) / sizeof(opts[0]),
.allow_positional = true,
.usage = "barg [options] [--] [files]",
.summary = "Sample program for barg",
};
barg_result_t result = barg_parse(&barg, argc, argv);
if (result.status != BARG_OK) {
// Print the help text or the error message accordingly
barg_print_result(&barg, result, stderr);
return result.status == BARG_SHOW_HELP ? 0 : 1;
}
// On success, arg_index is the index of the first positional argument
for (int i = result.arg_index; i < argc; ++i) {
printf("input: %s\n", argv[i]);
}
