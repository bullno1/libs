Detailed Description

A list of items collected from all compilation units.

For when you have a list of things (test cases, metadata...) spread around in different compilation units and you need to iterate over all of them.

Any compilation unit can add an entry to a list with AUTOLIST_ENTRY. Exactly one compilation unit defines the list with AUTOLIST_DEFINE (or AUTOLIST_DECLARE and AUTOLIST_IMPL separately) and every unit that includes the declaration can iterate over the collected entries with AUTOLIST_FOREACH.

Entries are collected by the linker into a dedicated section so there is no runtime registration.
