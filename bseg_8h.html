Detailed Description

Segmented array with stable element pointers.

Unlike barray.h, elements are never relocated when the array grows. Storage is a series of segments, each twice the size of its predecessor. Growing allocates a new segment instead of reallocating, so pointers to existing elements remain valid until the array is freed.

The tradeoff is that elements are not contiguous so they can only be accessed through bseg_at / bseg_ref instead of plain indexing. Random access is still O(1): locating a segment is a single bit scan.

Based on: https://danielchasehooper.com/posts/segment_array/

Usage:

bseg(int) numbers = { 0 }; // Zero-initialized means empty
bseg_push(numbers, 42, NULL);
int* first = bseg_ref(numbers, 0); // Valid until bseg_free
bseg_at(numbers, 0) += 1;
bseg_free(numbers, NULL);
